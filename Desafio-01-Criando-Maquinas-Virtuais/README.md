## Conceitos Aprendidos

### Máquina Virtual

Uma Máquina Virtual permite executar sistemas operacionais e aplicações em um ambiente virtualizado na nuvem.

### Grupo de Recursos

Utilizado para organizar e gerenciar recursos relacionados dentro do Azure.

### Rede Virtual

Permite a comunicação segura entre recursos implantados na nuvem.

### Endereço IP Público

Possibilita o acesso externo à máquina virtual.

## Conclusão

Durante este laboratório foi possível compreender na prática o processo de criação, configuração e gerenciamento de Máquinas Virtuais no Microsoft Azure, reforçando conceitos fundamentais de computação em nuvem.
