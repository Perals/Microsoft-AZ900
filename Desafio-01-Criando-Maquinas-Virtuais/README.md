# Desafio 01 - Criando Máquinas Virtuais na Azure

## 📖 Descrição

Este desafio teve como objetivo aplicar os conhecimentos adquiridos sobre Máquinas Virtuais no Microsoft Azure.

## 🎯 Objetivos

- Criar uma VM no Azure
- Configurar recursos de rede
- Compreender grupos de recursos
- Documentar o processo utilizando GitHub

## ☁️ O que é uma Máquina Virtual?

Uma Máquina Virtual (VM) é um computador virtual executado na nuvem permitindo hospedar aplicações, serviços e sistemas operacionais.

## 🚀 Etapas Realizadas

### 1. Acesso ao Portal Azure

Realizado login no Portal Microsoft Azure.

### 2. Criação da VM

Seleção do serviço Máquinas Virtuais e criação de um novo recurso.

### 3. Configurações Básicas

- Nome da VM
- Região
- Grupo de Recursos
- Sistema Operacional

### 4. Configuração de Rede

- Rede Virtual
- Endereço IP
- Regras de Firewall

### 5. Validação

Revisão das configurações antes da implantação.

### 6. Implantação

Criação da VM concluída com sucesso.

## 📚 Conceitos Aprendidos

- Computação em Nuvem
- Máquinas Virtuais
- Resource Groups
- Redes Virtuais
- Segurança

## ✅ Conclusão

O laboratório permitiu compreender o processo de criação e gerenciamento de Máquinas Virtuais utilizando a plataforma Microsoft Azure.
